# 外部 Agent 接入说明 - 2026-05-03

## 用途

本文用于把另一个对话框、OpenCode、DeepSeek 或其他外部 agent 纳入本项目的主 agent 管理流程。

核心原则：外部 agent 不能直接替代主 agent 做最终判断。它只负责产出可审查证据包；主 agent 读取后决定采纳、部分采纳、待核验或弃用。

## 外部 agent 回传格式

外部 agent 完成后，主 agent 只需要读取它写入的 `AgentWork/外部Agent报告-*.md`。如果它不能直接写文件，用户可以把它的最终回答复制到同名 Markdown 文件，或直接粘贴给主 agent。

## 主 agent 接收规则

主 agent 接收外部 agent 输出时必须检查：

| 检查项 | 处理 |
| --- | --- |
| 是否越权修改正式笔记、代码或原始资料 | 若越权，先标为风险，不直接采纳 |
| 是否编造文献、数据或实验结果 | 若发现，弃用相关内容 |
| 是否有明确来源或可复现实验输出 | 有则可部分采纳 |
| 是否区分事实、推断、假设和待核验 | 未区分则要求重写或由主 agent 重标 |
| 是否与当前路线一致 | 不一致时记录为备选，不直接进入主线 |

## 当前可交给外部 agent 的任务

优先任务仍然是项目本身，不继续扩展协作系统：

1. 精读 Dong2012，提取全线型拟合模型、介电函数、评价指标和参数表。
2. 阅读 `GB/T 42905-2023` 标准全文，提取红外反射法测厚公式、适用范围、峰位选择和精密度要求。
3. 设计 Airy/TMM 全谱拟合的公式说明，不写代码，只写输入、输出、参数和评价指标。
4. 查找并核验更适合 4H-SiC 外延层的红外 `n,k` 或介电函数数据。

## 不适合交给外部 agent 的任务

- 决定最终厚度。
- 决定论文最终贡献。
- 直接改正式论文结构。
- 直接把待核验文献写进参考文献终稿。
- 修改 `Code/` 核心脚本。
