# AgentWork 使用说明

本目录用于保存 [[碳化硅外延层厚度确定研究]] 的多 agent 协作证据包。

## 用途

- 存放子 agent 的阶段性输出。
- 存放尚未被主 agent 审查和整合的候选材料。
- 降低主上下文压力，让下一位 agent 可以只读必要证据包。

## 命名建议

```text
角色-任务-YYYY-MM-DD.md
```

示例：

```text
文献任务-Li2010之外核心文献核验-2026-05-03.md
数据任务-附件3和4硅厚度差异复核-2026-05-03.md
代码任务-色散FOD输出复核-2026-05-03.md
审查任务-单位与公式一致性检查-2026-05-03.md
```

## 状态标记

| 状态 | 含义 |
| --- | --- |
| 待审查 | 子 agent 已完成，但主 agent 尚未核验 |
| 已采纳 | 主 agent 已整合到正式项目笔记 |
| 部分采纳 | 部分内容可用，部分需要修正 |
| 待核验 | 来源、公式、数据或结论仍需验证 |
| 弃用 | 经审查不适合当前项目 |

## 禁止事项

- 不在本目录放原始 PDF、Excel 或未说明来源的数据。
- 不把本目录内容直接当最终论文结论。
- 不覆盖已有任务报告。
