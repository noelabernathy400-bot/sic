## 展示论文可见摘要信息

### B060

- 已核验标题：红外干涉法测量外延层厚度的建模分析。
- 已核验关键词：折射率建模、牛顿迭代反演、三次样条拟合、机器学习。
- 已核验摘要要点：
  - 提出基于牛顿迭代反演反射率模型参数、同基于波谷周期关系进行厚度计算交叉印证的路径。
  - 问题一使用碳化硅和硅的光强折射率物理模型、双光束干涉反射强度公式、Drude 折射率模型，给出直接计算外延层厚度的公式。
  - 问题二包含周期波谷直接计算法和牛顿迭代反演法；首页摘要可见碳化硅厚度结果约为 7.544 μm、7.295 μm，作为有效值约 7.544 μm。
  - 问题三建立多光束干涉模型，比较直接计算法与迭代反演法，并通过检验指标判断附件 1、2 中多光束干涉影响较弱，最终可信厚度值约 7.455 μm。
  - 对附件 3、4 的硅厚度，首页摘要可见直接计算和迭代计算给出约 3.453 μm、3.414 μm，最终取约 3.432 μm。
- 待下载核验：完整公式、数据预处理细节、机器学习实际用途、三次样条拟合的位置、检验指标 G 的定义和推导需逐页核验。

### B157

- 已核验标题：碳化硅外延层厚度的双光束和多光束干涉法测量研究。
- 已核验关键词：外延层厚度测量、傅里叶变换、多光束干涉、Cauchy 色散模型、Airy 公式。
- 已核验摘要要点：
  - 问题一构建双光束干涉模型，使用 Snell 定律修正入射角，考虑 Fresnel 公式计算空气/外延层、外延层/衬底反射系数，引入 Cauchy 色散模型描述折射率随波长变化。
  - 通过傅里叶变换获得干涉条纹周期，并根据振荡周期得到厚度初值，随后用非线性最小二乘拟合模型参数。
  - 问题二先进行等间距重采样，截断 1000 cm^-1 以下低波数干扰区，采用 Savitzky-Golay 平滑，随后通过滑窗傅里叶变换筛选有效频段，采用双角联合拟合策略。
  - 首页摘要可见 SiC 外延层厚度约 7.604 μm，残差均方根低于 1.14e-3，并提到对入射角、角度一致性、系统敏感性等做可靠性检验。
  - 问题三构建 Airy 多光束干涉 + Cauchy 色散模型，用滑窗 FFT 提取主频、选择有效带宽，估计 SiC/Si 界面反射率约 0.016；认为高阶反射贡献可忽略，最终将多光束模型退化为 Airy 型多光束干涉 + Cauchy 色散模型。
  - 首页摘要可见硅晶圆片厚度约 3.814 μm，残差主单位量级接近实验条纹，幅值整体小于 0.02。
- 待下载核验：滑窗 FFT 参数、有效频段 [1170, 2170] cm^-1 与 [2500, 3700] cm^-1 的完整上下文、随机梯度下降/全参数拟合细节、残差指标定义需逐页核验。

## 官方讲评中可借鉴的方法元素

### 数据预处理

- 已核验事实：讲评页展示了附件 1、2 反射率数据滤波前后的对比图；B157 摘要明确提到等间距重采样、截断低波数干扰区、Savitzky-Golay 平滑和滑窗 FFT 频段筛选。
- 可借鉴：本项目后续写论文时，应把“原始谱线 -> 重采样 -> 波段筛选 -> 平滑/极值检测 -> 残差检查”画成一条清晰流程，并为每一步说明目的和对厚度的影响。
- 推断/待下载核验：讲评是否推荐某一固定滤波参数，需逐页核验，不能直接编造窗口长度或阈值。

### 峰谷 / FOD 厚度估计

- 已核验事实：讲评给出基于相邻峰或谷的厚度计算公式，并强调波峰之间的间隔数 N；讲评还展示了常用的常数折射率峰距公式和线性回归法。
- 可借鉴：把 FOD 作为基线模型是官方材料中反复出现的路线，但必须明确折射率是否取常数、色散函数还是平均值；同类峰/谷与混合峰谷的级次口径要写清。
- 与当前项目关系：项目已发现同类极值相邻应按一级次差，这一点与官方讲评中“波峰数 - 1”的表达一致。

### 色散模型

- 已核验事实：B157 摘要直接使用 Cauchy 色散模型；讲评常见方法页指出有论文使用介电常数公式、色散方程公式和厚度公式。
- 可借鉴：论文中可把常数折射率 FOD 与色散修正 FOD 作为递进模型，明确 $n(\lambda)$ 或 $n(\omega)$ 的取值来源、适用波段和不确定性。
- 推断/待下载核验：B060 摘要提到 Drude 折射率模型，但其具体参数、单位和物理边界需逐页核验。

### 多光束 / TMM / Airy

- 已核验事实：讲评的问题三包含“多光束干涉的情况”；讲评页说明一次反射、一次透射-反射-再透射、三次反射等光路贡献；B157 摘要使用 Airy 多光束干涉 + Cauchy 色散模型。
- 可借鉴：本项目的 Dong/TMM 路线可以与官方 Airy/多光束路线对齐，但应更明确地区分：双光束近似、Airy 多光束闭式表达、TMM 全谱数值反演三者的适用条件。
- 推断/待下载核验：官方展示论文是否真正使用完整 TMM 形式，当前仅能确认 B157 使用 Airy 多光束，不能把它写成 TMM。

### 优化算法

- 已核验事实：讲评常见方法页展示了非线性最小二乘目标函数；B060 摘要提到牛顿迭代反演；B157 摘要提到非线性最小二乘拟合和随机梯度下降全参数拟合。
- 可借鉴：优化部分应避免只堆算法名。更可靠的写法是给出目标函数、参数边界、初值策略、多角度联合目标、收敛/局部最优检查和残差图。
- 推断/待下载核验：B060 的“机器学习”在摘要中作为关键词出现，但其是否真正提升模型可信度需逐页核验，不能直接作为可借鉴亮点。

### 误差分析

- 已核验事实：讲评进一步讨论了反射率误差、入射角误差和多光束影响；B157 摘要提到入射角、角度一致性、系统敏感性等可靠性检验；B060 摘要提到用检验指标判断多光束效应强弱。
- 可借鉴：本项目应优先强化角度一致性、残差谱结构、参数敏感性、波段敏感性和 bootstrap/置信区间，而不是只报告单个厚度值。
- 推断/待下载核验：各展示论文的误差传播公式、置信区间和评价指标定义需完整下载/阅读后才能引用。

### 论文结构与图表表达

- 已核验事实：讲评目录按“题目背景 -> 问题 1 数学模型 -> 问题 2 算法与计算 -> 问题 3 多光束干涉 -> 进一步讨论及结论 -> 常见方法 -> 参考文献”组织；展示论文均有摘要、关键词、分问题叙述。
- 可借鉴：当前项目论文可以采用“物理图像 + 基线公式 + 数据处理 + 色散修正 + 多光束/TMM + 误差与稳健性”的递进结构；图表上应展示滤波前后、峰谷识别、不同角度拟合、残差、敏感性热力图和结果对比表。
- 推断/待下载核验：展示论文内部图表质量、版式细节、附录代码是否公开，需逐页核验。

## 对当前项目的建议

1. 官方材料明显支持“先 FOD，后色散，再多光束/Airy/TMM，最后误差分析”的递进结构；这与当前项目路线一致。
2. 官方展示论文 B060、B157 的厚度数值都偏向约 7.5-7.6 μm 的 SiC 结果，与当前 Dong/TMM 候选区间有交叉，但不能因此直接证明当前模型正确；只能作为外部官方展示材料的方向参照。
