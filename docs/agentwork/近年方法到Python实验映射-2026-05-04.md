# 近年方法到 Python 实验映射

## 任务边界

本报告不继续查找或编造外部论文，只从方法类别角度，把可能有价值的近年建模思路映射为本项目可落地的 Python 实验路线。

已阅读项目材料：

- `Status.md`
- `Handoff Note.md`
- `Notes/建模与调试过程记录.md` 后半部分
- `Code/README.md`
- 补充阅读：`Overview.md`、`Task List.md`、`Decision Log.md`

当前已有模型链条可以概括为：

$$
\text{常数折射率 FOD}
\rightarrow
\text{色散修正 FOD}
\rightarrow
\text{Airy/TMM 调试}
\rightarrow
\text{Dong2012 介电函数 TMM}
\rightarrow
\text{参数敏感性、坐标搜索、局部细化、不确定性分析}
$$

当前最强候选口径仍应写作：

$$
d\approx 7.4\text{--}7.6\ \mu m
$$

其中有 $\nu_p$ 物理边界的局部细化代表值为：

$$
d^\ast=7.465\ \mu m,
\qquad
\mathrm{RMSE}_{\mathrm{joint}}=0.00171152.
$$

但外延层 $s_{\nu_p}=1.75$ 触及候选上界，因此不能把该材料参数解释成内部最优或真实掺杂结论。下一步实验应优先回答“厚度候选是否稳定、残差结构是否合理、参数是否可识别”，而不是单纯追求更低 RMSE。

## 路线 1：FFT 初值与频域修正

### 输入

- 附件 1、2 的 SiC 反射率谱，必要时也可对附件 3、4 的 Si 谱做对照。
- 波数 $\nu$、反射率 $R(\nu)$、入射角 $\theta$。
- 当前可选折射率口径：常数 $n=2.60$、Larruquert 插值 $n(\nu),k(\nu)$、Dong/TMM 给出的 $n(\nu),k(\nu)$。
- 待比较波段，例如全部有效波段、高波数波段、不含 Reststrahlen 区的波段。

### 输出

- 每个角度、每个波段的主频率或主周期。
- 由频域主峰反推的厚度初值 $d_0$。
- 频域峰清晰度指标，例如主峰能量占比、第二峰比值、窗口间厚度漂移。
- 可选输出频域滤波后的谱线，用于观察干涉条纹是否被基线或吸收区污染。
- 输出文件可设为：
  - `Experiments/outputs/fft_frequency_seed_results.csv`
  - `Experiments/outputs/fft_frequency_seed_summary.md`
  - `Experiments/figures/fft_frequency_seed_*.svg`

### 需要新增代码

建议新增：

```text
Code/fft_frequency_seed.py
```

核心函数建议：

- `resample_uniform_wavenumber()`：把原始波数数据重采样到等间隔网格。
- `detrend_reflectance()`：去除慢变背景，只保留条纹振荡。
- `estimate_fringe_frequency()`：用 FFT 或窗口 FFT 找主频。
- `frequency_to_thickness()`：把频域周期换算为厚度初值。
- `run_band_windows()`：对多个波段和角度重复计算。
- `write_summary()`：输出表格和解释。

厚度换算口径可先使用近似：

$$
\Delta \nu
\approx
\frac{1}{2d\sqrt{n^2-\sin^2\theta}},
$$

因此：

$$
d
\approx
\frac{1}{2\Delta\nu\sqrt{n^2-\sin^2\theta}}.
$$

若使用色散模型，则把常数 $n$ 替换为波段内的有效 $n_{\mathrm{eff}}$，并把这个近似结果只作为初值，不作为最终厚度。

### 和现有代码怎么连接

- 读取数据可复用 `spectral_pipeline.py` 的 `read_dataset()`。
- 平滑和极值口径可对照 `moving_average()`、`separated_extrema()`。
- 常数折射率厚度换算可对照 `interval_thickness_um()`、`fit_fod()`。
- 色散折射率可复用 `load_larruquert_sic_nk()`、`interpolate_nk()`。
- FFT 给出的 $d_0$ 可以作为 `dong2012_tmm_coordinate_search.py`、`dong2012_tmm_local_refinement.py`、`dong2012_tmm_constrained_refinement.py` 的厚度搜索中心或初始网格范围。
- `model_route_comparison.py` 可新增 `load_fft_frequency_seed()`，把 FFT 初值作为“频域独立初值”加入路线对比。

### 预期能回答的模型问题

- 反射谱中是否存在稳定的干涉主周期？
- 频域主周期支持 $6.1\ \mu m$ 附近，还是更支持 $7.4\text{--}7.6\ \mu m$？
- $10^\circ$ 与 $15^\circ$ 的频域厚度是否一致？
- 哪些波段的条纹周期最稳定，哪些波段可能受吸收、基线或 Reststrahlen 区影响？
- TMM 搜索是否需要从更宽厚度范围开始，还是可以围绕 FFT 初值做局部优化？

### 风险

- FFT 假设条纹近似平稳，但实际 $n(\nu),k(\nu)$ 色散会让周期随波数变化。
- 原始波数采样若不等间隔，必须先重采样，否则频率轴会错。
- 慢变背景、吸收区和仪器噪声会制造虚假频域峰。
- 有限窗口会带来谱泄漏；需要比较不同窗函数和不同波段。
- 频域厚度只能作为初值和诊断，不能替代 TMM 全谱拟合。

## 路线 2：Cauchy / Sellmeier-Drude 折射率模型

### 输入

- 波数 $\nu$ 或波长 $\lambda$。
- 当前 Larruquert 插值得到的 $n(\nu),k(\nu)$。
- Dong2012 介电函数参数及其缩放状态。
- 已建立的 $\nu_p$ 与载流子浓度 $N$ 的候选边界。
- 后续若用户提供或核验新的材料参数，可作为新的参数先验；本报告不新增外部文献数值。

### 输出

- 统一的折射率模型接口：

$$
n(\nu),\quad k(\nu),\quad \varepsilon(\nu)
$$

- 多类参数化模型的可比较结果：
  - 常数 $n$。
  - 插值型 $n(\nu),k(\nu)$。
  - Cauchy 型透明区近似。
  - Sellmeier 型色散项。
  - Drude 或 Sellmeier-Drude 型自由载流子修正。
- 每类折射率模型下的厚度低谷、RMSE、参数边界触及状态。
- 输出文件可设为：
  - `Experiments/outputs/refractive_model_comparison.csv`
  - `Experiments/outputs/refractive_model_comparison_summary.md`

建议新增共享模块：

核心函数建议：

- `constant_n_model()`
- `interpolated_nk_model()`

该脚本不应一次性自由拟合过多参数，而应先做固定参数、少量缩放参数、物理边界内网格三档实验。

### 和现有代码怎么连接

- `spectral_pipeline.py` 中的 `load_larruquert_sic_nk()`、`interpolate_nk()` 可迁移或包装进 `refractive_models.py`。
- `dong2012_dielectric_debug.py` 中的 `dong_epsilon_perp()`、`nk_from_epsilon()` 可作为 Dong 模型适配器。
- `dong2012_plasma_boundary.py` 中的 $N$-$\nu_p$ 换算可用于限制 Drude 项。
- `dong2012_tmm_sensitivity.py`、`dong2012_tmm_gamma_sensitivity.py`、`dong2012_tmm_phonon_sensitivity.py` 可逐步改为调用统一折射率接口，减少重复实现。
- TMM 端仍使用当前 `airy_reflectance()` 或 Dong/TMM 反射率计算，只替换材料模型输入。

### 预期能回答的模型问题

- 常数折射率、插值色散、参数化色散和 Dong/Drude 模型分别会把厚度推向哪里？
- 当前 $7.4\text{--}7.6\ \mu m$ 候选区间是 TMM 结构导致的，还是某一组 Dong 参数迁移导致的？
- $\nu_p$、$\gamma$、声子阻尼对 $n(\nu),k(\nu)$ 的影响是否具有物理可解释性？
- 是否存在一个更少参数、更稳定的折射率模型，能解释双角度数据而不过度拟合？

### 风险

- Cauchy 模型通常更适合弱吸收透明区，若跨越强吸收或 Reststrahlen 区，会失真。
- Sellmeier-Drude 模型参数多，可能出现多个参数组合给出相近 RMSE 的不可识别问题。
- 若没有独立材料参数或电学测量，不能把拟合出的 $\nu_p$、$\gamma$、阻尼参数解释为样品真实物性。
- 单位容易出错，尤其是 $cm^{-1}$、$\mu m$、Hz、rad/s 的换算。
- 统一接口改造会影响多份脚本，建议先新增模块并让新实验调用，不直接重构旧脚本。

## 路线 3：全局优化 / 模拟退火

### 输入

- 当前 Dong/TMM 双角度数据读取流程。
- 厚度 $d$。
- 折射率模型参数或缩放参数，例如：

$$
s_{\nu_p,\mathrm{epi}},\quad
s_{\nu_p,\mathrm{sub}},\quad
s_{\gamma,\mathrm{epi}},\quad
s_{\gamma,\mathrm{sub}},\quad
s_{\Gamma_L},\quad
s_{\Gamma_T}
$$

- 已建立的 $\nu_p$ 候选物理边界。
- 待补充的 $\gamma$ 与声子阻尼经验边界。
- 评价指标：联合 RMSE、分角度 RMSE、边界惩罚、残差结构指标。

### 输出

- 全局或准全局搜索得到的候选参数集。
- 最优值之外的前若干名候选，用于观察等价解和参数不可识别。
- 接受轨迹或温度轨迹，若使用模拟退火。
- 多随机种子重复结果。
- 参数边界触及表。
- 输出文件可设为：
  - `Experiments/outputs/tmm_global_optimization_candidates.csv`
  - `Experiments/outputs/tmm_global_optimization_runs.csv`
  - `Experiments/outputs/tmm_global_optimization_summary.md`

### 需要新增代码

在当前没有 `scipy` 的环境下，建议先新增纯 Python / numpy 版本：

```text
Code/tmm_global_optimization.py
```

核心函数建议：

- `evaluate_candidate(state)`：复用当前 TMM 评价函数。
- `random_latin_hypercube()` 或 `random_box_samples()`：先做全局随机覆盖。
- `simulated_annealing()`：从多个初始点启动模拟退火。
- `coordinate_polish()`：对退火结果接当前已有局部坐标细化。

如果后续安装 `scipy`，可再增加差分进化、dual annealing 或 least_squares，但不应让依赖安装成为当前路线的前置阻塞。

### 和现有代码怎么连接

- 直接复用 `dong2012_tmm_coordinate_search.py` 的 `apply_scales()`、`evaluate_state()` 思路。
- 复用 `dong2012_tmm_local_refinement.py` 的局部细化逻辑作为最后 polish。
- 复用 `dong2012_tmm_constrained_refinement.py` 的 `group_bounds()`、`boundary_status()` 口径。
- 复用 `dong2012_tmm_uncertainty.py` 的 profile objective 思路，对最终候选做厚度剖面。
- 最终由 `model_route_comparison.py` 新增一项“受约束全局/退火优化”。

### 预期能回答的模型问题

- 当前 $d^\ast=7.465\ \mu m$ 是否只是坐标搜索路径依赖的局部低谷？
- 在物理边界内，是否存在多个 RMSE 接近但厚度明显不同的候选解？
- 参数触边是否是因为边界太窄，还是因为模型结构无法解释部分谱线？
- $\nu_p$、$\gamma$、声子阻尼和厚度之间是否存在强耦合？
- 当前“候选区间”能否从搜索路径稳定升级为优化稳定？

### 风险

- 优化器容易追逐 RMSE，把材料参数推到不合理边界。
- 参数维度过高时，模拟退火可能需要大量计算。
- 没有物理边界的全局优化会产生看似更优但不可解释的结果。
- 多随机种子若给出不同厚度，需要诚实报告不可识别，而不是只挑最低 RMSE。
- 如果继续使用仿射校准反射率，优化可能吸收了仪器背景误差，需同时检查残差。

## 路线 4：TMM 联合拟合

### 输入

- 附件 1、2 的双角度 SiC 谱。
- 可选加入附件 3、4 的 Si 谱作为方法对照，但不建议一开始把 Si 和 SiC 混合进同一个材料参数模型。
- 统一折射率模型输出 $n(\nu),k(\nu)$ 或 $\varepsilon(\nu)$。
- 厚度 $d$。
- 每个角度的仪器背景校正参数，例如仿射校准：

$$
R_{\mathrm{obs}}(\nu)\approx aR_{\mathrm{model}}(\nu)+b.
$$

- 波段选择、权重函数和偏振口径。

### 输出

- 双角度联合最佳厚度和参数。
- 每个角度单独最佳厚度与联合厚度的差异。
- 拟合谱线、残差谱线、按波段分解的 RMSE。
- 参数边界触及状态。
- 可选输出偏振分量或非偏振平均结果。

### 预期能回答的模型问题

- 双角度是否能由同一厚度和同一材料参数同时解释？
- $10^\circ$ 与 $15^\circ$ 的残差差异是否集中在某些波段？
- 当前 $15^\circ$ RMSE 更高，是噪声、波段问题、偏振问题，还是材料模型不足？
- 仿射背景校正是否过度吸收了模型误差？
- 当前局部代表值 $7.465\ \mu m$ 能否在更规范的联合拟合脚本中复现？

### 风险

- 当前 TMM 仍可能是 Airy 单层形式，若实际光学路径涉及偏振、粗糙界面、多层或各向异性，残差会有系统结构。
- 双角度联合拟合可能牺牲某个角度的局部最优，需要用残差诊断解释。
- 若背景校正过强，RMSE 改善不等于物理模型更好。
- 如果把所有参数同时放开，会变成不可解释的曲线拟合。
- 需要严格记录“联合拟合值”“单角度值”“固定参数代表值”三种口径，避免论文表述混乱。

## 建议优先级

### 第一优先级：残差诊断

建议先做 `residual_diagnostics.py`。理由是项目交接中已经明确下一步是检查有边界最终状态下 $10^\circ$ 与 $15^\circ$ 的残差结构。它能直接服务当前主线，也能决定后续是改波段、改折射率模型，还是改优化方式。

### 第二优先级：FFT 初值

FFT 初值实现成本低，且能提供独立于 TMM 参数的频域证据。它适合作为“厚度候选是否由条纹周期支持”的外部 sanity check。

### 第三优先级：统一折射率模型接口

当残差诊断指出某些波段或角度存在系统问题后，再做 `refractive_models.py` 更有方向。否则容易变成盲目堆参数。

### 第四优先级：TMM 联合拟合

联合拟合应在折射率接口和残差诊断框架较清楚后推进。它是论文最终模型的候选主干，但需要避免一次性放开太多参数。

### 第五优先级：全局优化 / 模拟退火

全局优化适合在边界、评价指标和残差诊断都明确后进行。否则它可能只会更快地把参数推向边界，产生更低 RMSE 但更弱解释性的结果。

## 推荐最小实验序列

```text
1. residual_diagnostics.py
   回答：当前 10° / 15° 残差差异在哪里？

2. fft_frequency_seed.py
   回答：频域主周期是否支持当前 7.4--7.6 μm 候选区间？

3. refractive_models.py + refractive_model_comparison.py
   回答：不同折射率模型是否改变厚度低谷和残差结构？

4. tmm_joint_fit.py
   回答：双角度是否能由同一厚度和同一材料模型统一解释？

5. tmm_global_optimization.py
   回答：候选解是否为边界内稳定低谷，还是路径依赖局部解？
```

## 总结

这五条路线不是并列堆砌，而应形成递进关系：

$$
\text{残差定位问题}
\rightarrow
\text{FFT 提供独立初值}
\rightarrow
\text{折射率模型解释物性}
\rightarrow
\text{TMM 联合拟合建立主模型}
\rightarrow
\text{全局优化检查稳定性}
$$

本项目当前已经有较完整的 Dong/TMM 实验链条，下一阶段最有价值的不是继续扩大参数搜索，而是把“厚度稳定”和“残差可解释”同时纳入评价。只有当 $d\approx7.4\text{--}7.6\ \mu m$ 在频域、折射率模型、联合拟合和残差诊断中都能保持一致时，才适合把它从“当前最强候选区间”推进为论文中的核心结论。
