## 风险

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 已有论文中的折射率数据来源与样品不完全匹配 | 厚度结果可能只是形式上合理，物理可信度不足 | 核验 Larruquert 数据适用范围，并引入折射率不确定性分析 |
| 用经验多项式验证反射率 | 只能说明曲线可拟合，不能证明厚度可信 | 改为薄膜光学模型或转移矩阵法反演 |
| 多光束干涉修正推导不够严格 | 修正量和可靠性指标可能缺少真实支撑 | 使用 Airy/TMM 统一建模，并做残差与置信区间分析 |
| 极值提取对平滑窗口敏感 | 厚度估计可能随算法参数变化 | 做峰谷提取参数敏感性分析 |
| 硅厚度结果与初步峰距基线不一致 | 可能暴露单位、折射率或极值识别错误 | 优先复现附件 3、4 的硅厚度计算 |
