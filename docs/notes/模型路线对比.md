# 模型路线对比

## AI 深挖记录 - 2026-05-03

## 总体判断

本项目不应只采用一个模型。更合理的结构是“模型层级递进”：先用简单模型建立直觉，再用改进模型提高稳定性，最后用物理全谱模型处理多光束干涉。

## 路线 A：标准峰距法

### 核心思想

在高波数稳定干涉区提取相邻峰峰或谷谷间距，用近似公式估计厚度：

```text
d ≈ 10000 / (2 n cos(theta1) Δnu)
```

### 输入

- 波数-反射率数据
- 入射角
- 常数折射率
- 峰谷位置

### 输出

- 每个间隔对应的厚度
- 厚度均值和标准差

### 优点

- 最简单，物理含义清楚。
- 适合作 baseline。
- 便于发现明显异常，比如当前 Si 结果与旧论文 5.13 $\mu m$ 不一致。

### 缺点

- 对峰谷提取敏感。
- 折射率常数假设较强。
- 不处理吸收和多光束全谱形状。

### 适用条件

- 条纹周期明显。
- 折射率在选定波段变化较小。
- 只需要初步厚度量级。

### 论文表达难度

低。适合作为模型一。

## 路线 B：FOD 多极值拟合法

### 核心思想

参考 Li2010，不只使用相邻极值，而是选取多个极值点，拟合相对于参考点的 fringe order difference。对于峰-峰或谷-谷序列，相邻同类极值级次差为 1。

### 输入

- 峰序列或谷序列
- 入射角
- 折射率模型
- 参考极值点

### 输出

- 拟合厚度
- 拟合残差
- `R2` 或 RSS 等拟合指标

### 优点

- 比单个峰距更稳定。
- 已有 Li2010 文献支撑。
- 仍然比较容易解释。
- 可作为 TMM 的初始厚度。

### 缺点

- 仍依赖极值提取。
- 若折射率用常数，仍有色散误差。
- 对低质量条纹或错误极值敏感。

### 适用条件

- 有多个清晰极值点。
- 可以选取相对稳定波段。

### 论文表达难度

中等。适合作为论文主体模型之一。

## 路线 C：色散修正 FOD / 峰距法

### 核心思想

把常数折射率 `n` 换成随波数变化的 $n(\nu)$，必要时引入复折射率 $n(\nu)+ik(\nu)$。SiC 可先使用已下载的 Larruquert `n,k` 数据做插值，但必须标注其样品适用性风险。

### 输入

- 极值点波数
- $n(\nu)$ 或 `n,k` 插值
- 入射角

### 输出

- 色散修正厚度
- 与常数 n 模型的差异
- 折射率扰动敏感性

### 优点

- 正面回应题目“折射率不是常数”的要求。
- 可以把物理资料与数据计算连接起来。
- 有助于解释 SiC 低波数区和高波数区差异。

### 缺点

- 外部 `n,k` 不一定匹配题目样品。
- 如果没有样品掺杂浓度，无法完全确定折射率。
- 对 Si 数据也需要合理的硅折射率来源。

### 适用条件

- 有可靠或可说明适用边界的光学常数数据。
- 重点是比较修正前后差异，而不是假装外部数据就是题目真值。

### 论文表达难度

中等偏高。适合作为模型二或模型三。

## 路线 D：Airy / TMM 全谱拟合法

### 核心思想

直接建立空气-外延层-衬底多层结构的反射率模型，用整条反射率曲线拟合厚度。TMM 可以统一处理多光束干涉、复折射率、偏振和入射角。

### 输入

- 全谱波数和反射率
- 层结构
- 入射角
- 折射率模型
- 厚度初值

### 输出

- 全谱拟合厚度
- 拟合反射率曲线
- 残差图
- 修正前后厚度对比

### 优点

- 最适合回答问题三。
- 不只利用极值位置，也利用反射率曲线形状。
- 可替代旧论文中不可靠的经验多项式验证。

### 缺点

- 参数多，可能多解。
- 需要更谨慎处理基线、振幅、偏振、吸收和相干性。
- 论文表达和代码实现都更难。

### 适用条件

- 已有峰距/FOD 给出合理厚度初值。
- 能接受把部分参数固定或加入约束。

### 论文表达难度

高。适合作为最终增强模型，不适合一开始就直接使用。

## 不推荐作为核心路线：神经网络拟合折射率

### 为什么不推荐

神经网络可以拟合 `n,k` 曲线，但对本题的核心问题帮助有限：

- 一维平滑光学常数用插值或物理模型更可解释。
- 高 `R2` 只说明拟合了外部 `n,k` 数据，不说明厚度结果可信。
- 神经网络会转移论文重点，让模型看起来复杂但证据链变弱。

### 可以保留的方式

若后续确实需要，可把神经网络作为附录中的插值对比工具，而不是主模型。

## 推荐路线

当前最推荐的路线是：

```text
标准峰距法 -> FOD 拟合法 -> 色散修正 FOD -> Airy/TMM 全谱拟合 -> 稳健性分析
```

其中：

- 模型一解决“能不能从数据中得到厚度量级”。
- 模型二解决“多个极值点能否给稳定厚度”。
- 模型三解决“折射率变化会带来多大影响”。
- 模型四解决“多光束干涉如何修正和验证”。
- 稳健性分析解决“结果是否可信”。

## 当前最值得先做的模型

不是 TMM，而是 **FOD 参数敏感性 + Si 厚度复核**。

原因：

- TMM 需要合理初值。
- 当前 Si 结果存在明显疑点。
- 如果峰谷/FOD 结果本身不稳，TMM 拟合会变成黑箱。
