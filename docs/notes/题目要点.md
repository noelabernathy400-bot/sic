# 题目要点

## 基本信息

- 题目：2025 年高教社杯全国大学生数学建模竞赛 B 题“碳化硅外延层厚度的确定”
- 对象：碳化硅外延层、硅外延层
- 方法背景：红外干涉法
- 核心变量：波数、反射率、折射率、入射角、外延层厚度

## 题目核心

题目要求用红外反射光谱中的干涉条纹反推外延层厚度。折射率不是常数，而是与掺杂载流子浓度、红外波长等因素有关。

## 三个问题

1. 只考虑一次反射和透射，建立确定厚度的数学模型。
2. 基于问题一设计算法，用附件 1、2 的碳化硅数据计算厚度，并分析可靠性。
3. 推导多光束干涉必要条件，分析多光束干涉对厚度计算精度的影响；判断附件 3、4 的硅数据是否出现多光束干涉，建立硅厚度算法；如碳化硅也受多光束干涉影响，需要消除影响并给出修正结果。

## 评价重点

- 是否能同时解释两个入射角的数据。
- 厚度估计是否对峰谷提取、折射率模型、噪声和波数范围稳健。
- 多光束干涉判断是否有可计算证据，而不是只列物理条件。
- 结果是否可复现，图表是否支撑结论。
