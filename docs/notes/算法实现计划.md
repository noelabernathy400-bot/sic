## 2. 算法路线与输入输出

### 算法 A：标准峰距法

输入：

- 波数数组 `nu`
- 反射率数组 `R`
- 入射角 `theta0`
- 常数折射率 `n`
- 峰谷提取参数

输出：

- 峰谷位置
- 峰峰/谷谷间距
- 每个间距对应厚度
- 厚度均值、标准差

复杂度：

- 近似 `O(N)`，主要是平滑和极值扫描。

可解释性：

- 高。适合写入论文第一层模型。

### 算法 B：FOD 拟合法

输入：

- 峰序列或谷序列
- 入射角
- 折射率模型
- 参考极值点

输出：

- 拟合厚度 `d`
- RSS、R2
- 拟合残差

复杂度：

- 当前常数折射率版本近似为线性最小二乘，复杂度低。

可解释性：

- 较高。已有 Li2010 支撑，适合作为中间主模型。

注意：

- 峰-峰/谷-谷相邻极值级次差为 1。
- 峰谷混合序列才使用 0.5 级次差。

### 算法 C：FOD 参数敏感性分析

输入：

- 多组 `smooth_window`
- 多组 `min_spacing_cm`
- 多组波段 `[nu_min, nu_max]`
- 附件 1-4 数据

输出：

- 每组参数下的厚度
- 厚度均值、范围、标准差
- 哪些参数导致结果不稳定

复杂度：

- `O(GN)`，其中 `G` 是参数组合数量。

可解释性：

- 高。可以直接写成论文中的稳健性检验。

### 算法 D：Larruquert n,k 插值

输入：

- `Sources/Literature/SiC_Larruquert_refractiveindex.csv`
- 附件波数范围

输出：

- $n(\nu)$、$k(\nu)$ 插值函数
- SiC 题目波段内的折射率曲线

复杂度：

- 很低，插值为主。

可解释性：

- 中等。必须强调外部光学常数与题目样品可能不完全一致。

### 算法 E：TMM / Airy 全谱拟合

输入：

- 全谱 `nu, R_exp`
- 层结构
- 折射率模型
- 厚度初值
- 反射率 scale/offset 参数

输出：

- 最优厚度
- 拟合曲线
- 残差
- 单角度和双角度联合拟合结果

复杂度：

- 中等到高，取决于优化器和参数数量。

可解释性：

- 中等。需要把物理推导写清楚，否则容易变黑箱。
