# 新版论文总架构

## 写作定位

这篇论文不应再写成“堆模型名”的版本，而应写成一条可追溯的研究链：

```text
题目数据 -> 标准峰距基线 -> 多极值/FOD 修正 -> 色散折射率修正 -> Airy/TMM 全谱拟合 -> 稳健性与可信区间 -> 论文结论
```

核心亮点不是“用了神经网络”，而是：

- 每一步都有物理意义。
- 每个厚度结论能追溯到数据、模型和参数。
- 用两个入射角验证同一块晶圆片的厚度一致性。
- 用敏感性和稳健性分析说明结果可信。

## 摘要结构

摘要建议按四句话组织：

1. 背景：SiC 外延层厚度对器件性能重要，红外反射法可无损测量，但折射率色散和多光束干涉会影响厚度反演。
2. 方法：建立从单次反射峰距模型到多极值 FOD 拟合、再到 Airy/TMM 全谱反射率模型的递进算法。
3. 结果：报告 SiC、Si 在 10 deg 和 15 deg 下的厚度估计、联合拟合结果和可信区间。
4. 评价：通过角度一致性、峰值提取敏感性、折射率扰动和残差诊断验证模型可靠性。

## 第 1 章 问题重述

### 1.1 背景

- SiC 是第三代半导体材料。
- 外延层厚度影响器件性能。
- 红外反射法是非接触、无损测厚方法。

### 1.2 题目任务拆解

- 问题一：单次反射/透射下的厚度模型。
- 问题二：用附件 1、2 求 SiC 厚度并评价可靠性。
- 问题三：判断多光束干涉，求 Si 厚度，并修正 SiC 结果。

### 1.3 本文解决思路

本文分成四层：

1. 标准峰距模型。
2. 多极值 FOD 模型。
3. 色散折射率修正模型。
4. Airy/TMM 多光束全谱模型。

## 第 3 章 模型假设与符号说明

### 3.1 基础假设

建议把假设写成“可检验/可讨论”的形式：

| 假设 | 理由 | 风险 | 后续检查 |
| --- | --- | --- | --- |
| 外延层与衬底界面近似平行 | 干涉条纹清晰需要稳定光程差 | 粗糙度会降低条纹对比 | 残差和条纹稳定性 |
| 同一材料两个入射角对应同一厚度 | 附件说明为同一块晶圆片 | 测量误差或点位差异 | 角度一致性 |
| 高波数区适合峰距/FOD 模型 | Li2010 指出某些波段折射率变化较小、条纹稳定 | 波段选择影响结果 | 波段敏感性 |
| 折射率模型存在不确定性 | 题目未给掺杂浓度和 n,k | 外部光学常数可能不匹配 | n,k 扰动分析 |

### 3.2 符号说明

建议包括：

- `nu`：波数，$cm^{-1}$
- `lambda`：波长，um
- `d`：外延层厚度，um
- $n(\nu), k(\nu)$：复折射率实部和虚部
- `theta0, theta1`：入射角和折射角
- `R_exp, R_model`：实验反射率和模型反射率
- `m, Δp`：干涉级次和 fringe order difference

## 第 4 章 模型一：标准峰距基线模型

### 4.1 模型目的

不是追求最终最精确，而是建立透明、可复现的基准结果。

### 4.2 公式主线

相邻极值间距近似给出：

```text
d ≈ 10000 / (2 n cos(theta1) Δnu)
```

其中 $10000$ 用于处理 $cm^{-1}$ 到 $\mu m$ 的单位转换。

### 4.3 Python 实现

步骤：

1. 读取附件数据。
2. 选择高波数稳定区。
3. 平滑反射率曲线。
4. 提取波峰和波谷。
5. 分别计算峰峰、谷谷厚度分布。

### 4.4 输出

- 表：每个附件的峰/谷数量、平均峰距、厚度均值和标准差。
- 图：峰谷标注图。
- 结论：给出 SiC、Si 的初步厚度量级。

## 第 5 章 模型二：多极值 FOD 拟合模型

### 5.1 文献依据

Li2010 提出基于 fringe order difference 的拟合模型，旨在兼顾直接计算法的简单性和曲线拟合法的稳定性。该文对比 SEM 结果显示，FOD 拟合法比传统计算法更稳定。

### 5.2 本题改造

对每个附件：

1. 选择参考极值点。
2. 计算其它极值点相对参考点的半波数差。
3. 以厚度 `d` 和参考级次参数为拟合变量。
4. 使用最小二乘拟合。

### 5.3 作用

- 减少单个峰距误差。
- 提高 Si 和 SiC 两角度结果的一致性。
- 为后续全谱模型提供初值。

## 第 6 章 模型三：色散折射率修正模型

### 6.1 为什么需要

题目明确说明折射率与波长、载流子浓度等有关；Li2010 也指出，即使折射率变化很小，也会影响厚度，尤其薄膜样品。

### 6.2 三种折射率方案

| 方案 | 数据来源 | 用途 |
| --- | --- | --- |
| 常数 n | 文献/经验值 | baseline |
| Larruquert n,k 插值 | RefractiveIndex.INFO / Larruquert 数据 | SiC 色散修正 |
| Drude-Lorentz / MDF 参数模型 | Dong2012、Oishi2006 待精读 | 可解释的物理色散模型 |

### 6.3 输出

- 图：SiC `n,k` 随波数变化。
- 表：不同折射率方案下的厚度差异。
- 图：折射率扰动对厚度的敏感性。

## 第 7 章 模型四：Airy/TMM 多光束全谱拟合模型

### 7.1 为什么需要

问题三要求分析多光束干涉及其对厚度精度的影响。已有论文中的经验多项式拟合不能证明厚度可信，因为它没有厚度物理含义。

### 7.2 模型选择

两层实现：

1. 简化 Airy 公式：适合论文推导。
2. Python TMM：适合数值计算和验证。

Byrnes `tmm` 是 Python/NumPy 实现的薄膜光学转移矩阵法，可计算多层薄膜中的反射、透射、吸收和多重内部反射。

### 7.3 拟合目标

```text
min Σ [R_model(nu_i, d, params) - R_exp(nu_i)]^2
```

可选参数：

- 厚度 `d`
- 反射率基线偏移
- 振幅缩放
- 折射率模型参数

### 7.4 输出

- 图：实验反射率 vs TMM 拟合反射率。
- 图：残差随波数变化。
- 表：单角度拟合和双角度联合拟合结果。
- 表：SiC 修正前后厚度。

## 第 8 章 可靠性分析

### 8.1 角度一致性

同一晶圆片在 10 deg 和 15 deg 下应得到一致厚度。分别反演和联合反演都要报告。

### 8.2 峰谷提取敏感性

改变：

- 平滑窗口。
- 最小峰距。
- prominence 阈值。
- 选取波段。

### 8.3 折射率敏感性

扰动：

- 常数 n。
- Larruquert n,k 插值。
- Drude-Lorentz 参数。

### 8.4 统计不确定性

使用：

- Bootstrap 重采样。
- Monte Carlo 加噪声。
- 参数协方差近似。

输出厚度置信区间。

## 第 10 章 模型评价与改进

### 优点

- 从简单模型到复杂模型逐层递进。
- 两入射角联合约束增强可靠性。
- 不只报单点值，还报告不确定性。
- TMM 模型能统一解释多光束干涉。

### 局限

- 题目未给真实掺杂浓度，折射率模型仍有不确定性。
- 外部 SiC 光学常数可能与题目样品不完全一致。
- 缺少 SEM 或台阶仪等外部真值。
- 衬底厚度、背面反射、粗糙度等因素未必能完全建模。

### 改进

- 引入载流子浓度、迁移率与厚度联合反演。
- 引入椭偏或 SEM 对照数据。
- 对空间多点测量做厚度均匀性分析。
