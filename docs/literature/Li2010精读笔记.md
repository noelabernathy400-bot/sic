## 论文解决的问题

该文讨论如何用红外反射光谱确定 SiC 同质外延层厚度。作者指出 FTIR 是非破坏、非接触测量方法，可用于外延层厚度、载流子相关信息的表征；但传统厚度算法存在稳定性和复杂度问题。

## 关键方法分类

### 方法一：传统直接计算法

思路：选取两个干涉极值点，用干涉级次关系和厚度公式计算厚度。

问题：常把 SiC 折射率视为常数，但论文指出 SiC 折射率随入射频率变化，即使变化很小，也会影响厚度测量，尤其薄膜样品可用极值点更少时误差更明显。

### 方法二：全谱曲线拟合法

思路：用反射率模型拟合实测反射谱。论文给出类似 Airy 型多光束反射率形式：

```text
R = |(r1 + r2 exp(2iδ)) / (1 + r1 r2 exp(2iδ))|^2
```

其中 `r1`、`r2` 是空气/外延层与外延层/衬底界面的 Fresnel 反射系数，`δ` 是由光程差和半波损失导致的相位差。

优点：考虑折射率随频率变化，结果稳定准确。

缺点：需要外延层和衬底的详细信息，反射谱高度非线性，拟合复杂。

### 方法三：FOD 拟合法

思路：不直接拟合整条反射率曲线，而拟合极值点之间的 fringe order difference。作者选择一个参考极值点，然后用其它极值点相对于参考点的半波数差建立近似线性拟合。

优点：

- 只需外延层信息。
- 比全谱曲线拟合更简单。
- 比直接计算法稳定。

论文实验结论：FOD 拟合法与 SEM 测量结果高度一致，两个样品的平均相对误差约 0.4% 和 0.3%；传统直接计算法误差约 8% 和 9.4%。

## 对本项目的直接启发

### 1. 我们不能只用单个峰距公式

题目虽然可从峰距入手，但如果直接平均峰谷间距，很容易受到折射率色散、极值点选择和波段选择影响。

### 2. 需要把“标准法”和“改进法”分层

新版论文可以设计三层递进：

1. 标准峰距法：给出透明基线。
2. FOD / 色散修正峰距法：利用多个极值点拟合，减少单点误差。
3. TMM / Airy 全谱拟合法：处理多光束干涉，作为最终验证或高阶模型。

### 3. 波数区间不能随便选

Li2010 选择 1700-3000 $cm^{-1}$，是因为该区间折射率变化较小且条纹对比稳定。我们的附件范围是约 400-4000 $cm^{-1}$，也应显式解释为什么选某个波段，而不是全范围机械提峰。

### 4. 极值点选择是实验核心

论文指出干涉条纹中噪声或杂乱会影响人工识别极值点。我们应把这一点变成 Python 可复现实验：

- 平滑窗口敏感性。
- 极值 prominence 阈值敏感性。
- 峰峰、谷谷、峰谷混合策略对比。

### 5. 已有论文的神经网络亮点需要降级

Li2010 的逻辑说明：折射率频变重要，但不一定需要神经网络。更自然的方式是物理介电函数或 n,k 插值，再通过极值级次或反射谱拟合进入厚度反演。

## 可转化为本项目章节的内容

- 文献综述：FTIR 测厚方法分为直接计算法、曲线拟合法、FOD 拟合法。
- 方法设计：以直接计算法作为 baseline，FOD 拟合作为主模型之一。
- 模型评价：对比传统单峰距法和改进 FOD 法的稳定性。
- 实验设计：选取稳定波段，做极值提取参数敏感性。

## 仍需复核

- Li2010 的公式中波长、波数、频率符号转换需要与题目单位统一。
- 论文样品入射角为 16 deg，而题目是 10 deg 和 15 deg。
- 论文样品为 n-type 4H-SiC，同题目样品是否一致未知。
- 论文实验有 SEM 作为真值，本题没有外部真值，因此要用角度一致性和不确定性分析替代。
