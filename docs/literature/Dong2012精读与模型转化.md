# Dong2012 精读与模型转化

## 1. 为什么精读这篇文献

当前项目已经完成了三类中间模型：

1. 标准峰距法；
2. 常数折射率 FOD；
3. 色散修正 FOD；
4. Airy/TMM 最小调试模型。

这些模型暴露出一个核心问题：如果外延层和衬底的光学性质完全相同，厚度不可识别；如果强行加入人工折射率差，模型能拟合出条纹，但参数没有物理来源。

Dong et al. 2012 直接研究 4H-SiC 衬底和外延层的 FTIR 反射谱，并用全线型拟合同时估计外延层厚度、载流子浓度和迁移率。因此它最适合回答本项目下一步问题：

> 外延层和衬底的光学差异应该如何进入 TMM/Airy 模型？

## 3. Dong2012 的核心模型

### 3.1 介电函数：晶格振动 + Drude 项

Dong2012 将频率相关介电函数写成晶格振动项与自由载流子 Drude 项之和。按本项目符号整理为：

$$
\varepsilon_{\parallel,\perp}(\nu)
=
\varepsilon_{\infty,\parallel,\perp}
\left[
\frac{
\nu_{L,\parallel,\perp}^{2}
-\nu^{2}
-i\Gamma_L\nu
}{
\nu_{T,\parallel,\perp}^{2}
-\nu^{2}
-i\Gamma_T\nu
}
-
\frac{
\nu_{p,\parallel,\perp}^{2}
}{
\nu(\nu+i\gamma)
}
\right]
$$

其中：

| 符号 | 含义 |
| --- | --- |
| $\nu$ | 波数，单位 $\mathrm{cm}^{-1}$ |
| $\varepsilon_{\infty}$ | 高频介电常数 |
| $\nu_L$ | LO 声子频率 |
| $\nu_T$ | TO 声子频率 |
| $\Gamma_L$ | LO 阻尼常数 |
| $\Gamma_T$ | TO 阻尼常数 |
| $\nu_p$ | 等离子体频率 |
| $\gamma$ | 等离子体阻尼常数 |

注意：PDF 抽取文本中公式排版存在丢失括号的风险，上式是根据文意和抽取内容整理的可实现版本。正式论文使用前还应对照 PDF 版面截图或原文公式。

### 3.2 自由载流子浓度与等离子体频率

Dong2012 给出载流子浓度 $N$ 与等离子体频率 $\nu_p$ 的关系：

$$
\nu_{p,\parallel,\perp}
=
\frac{1}{2\pi c}
\sqrt{
\frac{Nq^2}
{m_{\parallel,\perp}^{*}\varepsilon_0\varepsilon_{\infty,\parallel,\perp}}
}
$$

这说明 $\nu_p$ 不是任意数学参数，而是与载流子浓度直接相关。

### 3.3 迁移率与等离子体阻尼

等离子体阻尼 $\gamma$ 与迁移率 $\mu$ 的关系为：

$$
\gamma_{\parallel,\perp}
=
\frac{1}{2\pi c}
\frac{q}
{m_{\parallel,\perp}^{*}\mu_{\parallel,\perp}}
$$

这说明全谱拟合不只是拟合厚度。若模型足够可信，它还能反推电学性质。

## 4. 外延层反射率公式

Dong2012 对外延层使用多次反射求和，形式与我们当前 Airy 调试模型一致。

非偏振反射率写成：

$$
R_{\mathrm{epi}}
=
\frac{R_p+R_s}{2}
=
\frac{|r_{p,\mathrm{epi}}|^2+|r_{s,\mathrm{epi}}|^2}{2}
$$

其中单层反射振幅为：

$$
r_{p,\mathrm{epi}}
=
\frac{
r_{1p}+r_{2p}\exp(2i\beta_p)
}{
1+r_{1p}r_{2p}\exp(2i\beta_p)
}
$$

$$
r_{s,\mathrm{epi}}
=
\frac{
r_{1s}+r_{2s}\exp(2i\beta_s)
}{
1+r_{1s}r_{2s}\exp(2i\beta_s)
}
$$

这里：

- $r_1$ 是空气/外延层界面 Fresnel 反射系数；
- $r_2$ 是外延层/衬底界面 Fresnel 反射系数；
- $\beta$ 是与厚度 $d$、介电函数和入射角有关的相位项。

这与我们已经写出的 Airy 调试模型：

$$
r(\nu;d)
=
\frac{
r_{01}+r_{12}\exp(2i\delta)
}{
1+r_{01}r_{12}\exp(2i\delta)
}
$$

是同一思想。区别在于 Dong2012 用介电函数模型生成外延层和衬底的复折射率，而我们上一轮只用了人工 $\Delta n$。

## 5. 可调参数和固定参数

Dong2012 在外延层拟合中使用 Eqs. (1), (2), (3), (6)，并把以下参数设为可调：

| 参数 | 含义 |
| --- | --- |
| $\nu_{p,\perp}$ | 与载流子浓度相关的等离子体频率 |
| $\gamma$ | 与迁移率相关的等离子体阻尼 |
| $\Gamma_L$ | LO 阻尼 |
| $\Gamma_T$ | TO 阻尼 |
| $d$ | 外延层厚度 |

固定参数包括：

| 参数 | Dong2012 取值 |
| --- | ---: |
| $\nu_{L,\perp}$ | $970.1\,\mathrm{cm}^{-1}$ |
| $\nu_{L,\parallel}$ | $965.8\,\mathrm{cm}^{-1}$ |
| $\nu_{T,\perp}$ | $797.3\,\mathrm{cm}^{-1}$ |
| $\nu_{T,\parallel}$ | $782.1\,\mathrm{cm}^{-1}$ |
| $\varepsilon_{\infty,\parallel}$ | $6.78$ |
| $\varepsilon_{\infty,\perp}$ | $6.56$ |
| $m_{\parallel}^{*}$ | $0.29m_0$ |
| $m_{\perp}^{*}$ | $0.42m_0$ |

## 6. 这篇文献怎样改变我们的模型路线

上一轮调试模型使用：

$$
\tilde n_2(\nu)=\tilde n_1(\nu)+\Delta n
$$

这是人为构造光学差异，只能调试代码。

Dong2012 提供了更合理的替代：

$$
\tilde n_1(\nu)=\sqrt{\varepsilon_{\mathrm{epi}}(\nu;\nu_{p,1},\gamma_1,\Gamma_{L,1},\Gamma_{T,1})}
$$

$$
\tilde n_2(\nu)=\sqrt{\varepsilon_{\mathrm{sub}}(\nu;\nu_{p,2},\gamma_2,\Gamma_{L,2},\Gamma_{T,2})}
$$

外延层和衬底差异不再是人工 $\Delta n$，而来自载流子浓度、迁移率和阻尼参数差异。

## 7. 对当前题目的直接启发

1. **题目附件只有 $400\text{--}4000\,\mathrm{cm}^{-1}$ 附近数据时，载流子迁移率可能不稳定。**  
   Dong2012 用 EQS 讨论了谱线对载流子参数的敏感性，指出低载流子浓度时中红外谱段对迁移率不够敏感。

2. **厚度比电学参数更容易稳定。**  
   Dong2012 的外延层厚度拟合与 SEM 接近，而低载流子浓度下电学参数误差更大。这提示本项目应把主目标放在厚度，电学参数只作为解释光学差异的辅助参数。

3. **全谱拟合要有评价指标。**  
   本项目可以借鉴 EQS 思想，设计：

$$
\mathrm{RSS}(d,\Theta)
=
\sum_{j=1}^{m}
\left[
R_{\mathrm{obs}}(\nu_j)
-
R_{\mathrm{model}}(\nu_j;d,\Theta)
\right]^2
$$

其中 $\Theta$ 表示光学参数集合。

4. **多角度一致性应成为本题亮点。**  
   Dong2012 是单入射角 $16^\circ$；本题有 $10^\circ$ 和 $15^\circ$。如果我们用同一厚度同时拟合两个角度，将比单角度更有说服力。

## 8. 下一步转化为 Python 的计划

下一步不直接做大规模优化，而是先做介电函数调试：

1. 写 `Code/dong2012_dielectric_debug.py`。
2. 输入 Dong2012 的固定声子参数和表 2 的外延层/衬底参数。
3. 计算：

$$
\varepsilon_{\perp}(\nu),
\quad
\tilde n(\nu)=\sqrt{\varepsilon_{\perp}(\nu)}
$$

4. 输出外延层与衬底的 $n(\nu)$、$k(\nu)$ 差异。
5. 将该差异替代 `tmm_air_debug.py` 中的人工 `contrast_delta_n`。

## 9. 不能直接照搬的部分

- Dong2012 的样品厚度是 $14.4\,\mu\mathrm{m}$，本题附件初步结果约在 $5\text{--}7\,\mu\mathrm{m}$，不能照搬厚度。
- Dong2012 使用 $16^\circ$ 入射角，本题是 $10^\circ$ 和 $15^\circ$。
- Dong2012 表 2 参数来自其样品，不能当作本题样品参数。
- Dong2012 的公式细节还需对照 PDF 版面，避免 PDF 文本抽取造成公式括号错误。

## 10. 当前结论

Dong2012 的最大价值不是提供一个可以抄的厚度，而是提供了本题从“峰位测厚”升级到“物理全谱拟合”的核心机制：

$$
\text{外延层/衬底光学差异}
\leftarrow
\text{载流子浓度、迁移率、声子阻尼}
\leftarrow
\varepsilon(\nu)
\leftarrow
R(\nu;d)
$$

这正好补上了上一轮 Airy/TMM 调试模型中人工 $\Delta n$ 的物理来源缺口。
