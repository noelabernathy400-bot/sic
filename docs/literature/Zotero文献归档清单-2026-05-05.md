## 9. 后续维护流程

推荐流程：

1. 继续使用 Zotero 集合 `SiC Epilayer Thickness Study` 作为本项目文献原件入口。
2. 对已经导入但元数据较粗的条目，优先用 Zotero 的 “Add Item by Identifier” 或 DOI 手动补全作者、期刊、年份、页码等字段。
3. 对已有 PDF，例如 Li2010 和 Dong2012，优先附加到 Zotero 条目，并使用“Retrieve Metadata for PDF”或手动绑定 DOI。
4. 对网页资料，用 Zotero Connector 保存网页快照或链接；vault 中只保留网页学习笔记和核验状态。
5. 回到 vault 文献笔记，在 frontmatter 或正文补充 Zotero citekey / Zotero select URI。
6. 只在 vault 中保留精读笔记、方法节点和引用追踪；不要继续把新 PDF 长期放入 `Sources/Literature/`。

