## 目标

根据用户要求，为当前数学建模项目新增一条项目级提醒规则：当研究任务预计消耗大量本地算力、上下文 token 或用户额度时，agent 需要主动提示是否考虑接入学校服务器或更合适的计算环境。

## 关键决定

- 该规则写成项目级规则，不提升为全局 `AGENTS.md` 规则，避免污染整个通用研究 vault。
- 触发场景包括大规模全局优化、机器学习仿真谱训练、MCMC/bootstrap、高分辨率参数扫描、批量 OCR/视频转写和长上下文文献精读。
- 默认先做小规模 sanity check，再判断是否扩大实验规模。
- 如果成本明显升高，必须提醒用户选择：继续本地小规模验证，或考虑接入学校服务器。
- 不默认假设用户有服务器权限；不把密码、私钥、长期 token 等敏感信息写入 vault。

## 风险或跳过事项

- 本次没有修改全局 `AGENTS.md`，因为用户当前要求服务于本数学建模项目。
- 本次没有创建服务器连接脚本，也没有请求或保存任何登录凭据。
- 本次没有启动高成本实验。

## 下一步建议

- 如果后续要做全局优化、仿真谱机器学习或大规模不确定性传播，先设计低分辨率本地验证版本。
- 低分辨率版本跑通后，再估计服务器运行所需依赖、数据规模、运行时间和输出文件结构。
- 若用户决定接入学校服务器，再单独建立安全的运行说明和临时连接流程。
