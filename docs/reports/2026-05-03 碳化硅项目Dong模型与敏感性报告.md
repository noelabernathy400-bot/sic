## 关键决定

- 将用户强调的“总研究叙事”写入项目规则：后续必须详细记录数据处理、建模、调试、公式、实验和不确定性。
- Dong2012 不作为可照抄的结果来源，而作为从人工折射率差过渡到介电函数 TMM 的模型来源。
- 用 Dong2012 表 2 参数接入本题数据只视为调试，不视为最终厚度。
- 第一版敏感性只缩放等离子体频率 `\nu_p`，用于检查厚度低谷是否随参数大幅漂移。

## 阶段性发现

- Dong2012 官方 PDF 已成功下载并抽取文本。第一次下载得到的是 HTML 访问页，已保留并标注，避免误当全文。
- Dong2012 介电函数可以转化为可运行的 Python 代码，并生成外延层/衬底复折射率。
- 使用 Dong2012 表 2 参数接入 Airy 模型后，本题 SiC 10 度和 15 度数据的误差低谷约在 `7.4 um` 附近。
- 缩放外延层/衬底等离子体频率后，联合误差低谷主要集中在 `7.4-7.6 um` 附近，说明当前 Dong/TMM 框架下厚度信号有一定稳定性。

## 风险或跳过事项

- `7.4-7.6 um` 仍不是最终厚度，因为参数没有从本题数据中最终拟合，也没有完成全参数敏感性。
- 当前 Dong 介电函数实现只使用 `\varepsilon_\perp`，尚未处理各向异性。
- PDF 文本抽取可能影响公式括号和符号，正式论文前需对照 PDF 原版公式。
- `git status --short` 仍受 dubious ownership 阻塞，本轮未修改全局 Git 配置。
