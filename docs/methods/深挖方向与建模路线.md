# 深挖方向与建模路线

## 总体策略

不要急着把已有论文润色成“更复杂”。更好的方向是把论文变成一条可复现、可比较、可解释的模型链：从附件数据出发，经过峰谷提取或全谱拟合，得到厚度，并用多角度一致性、敏感性分析和对比模型证明结果可信。

## 路线一：峰距法基线模型

### 核心思想

先建立最简单但透明的基线：从高波数稳定干涉区提取峰或谷，用相邻极值间距估计厚度。

### 优点

- 简单、可解释，适合作为所有复杂模型的参照。
- 能快速发现附件数据本身支持的厚度量级。
- 方便做峰谷提取参数敏感性分析。

### 局限

- 依赖折射率取值。
- 对噪声、平滑窗口、低频异常区敏感。
- 不充分利用整条反射率曲线。

## 路线二：色散修正峰距法

### 核心思想

将折射率写成 $n(\nu)$ 或复折射率 $n(\nu)+ik(\nu)$，用外部光学常数或物理色散模型校正峰距公式。

### 优点

- 比常数折射率更贴近题目“折射率不是常数”的要求。
- 能自然引入折射率不确定性分析。

### 局限

- 外部光学常数和题目样品可能不完全一致。
- 需要说明晶型、掺杂、温度、波段适用性。

## 路线三：Airy / 转移矩阵法全谱拟合

### 核心思想

直接建立薄膜-衬底-空气多层结构的反射率模型，对整条反射率曲线进行拟合，参数至少包括厚度 d，必要时包括折射率模型参数、基线漂移和振幅缩放。

### 优点

- 最适合回答问题三的多光束干涉。
- 能统一处理偏振、入射角、吸收、相位和多次反射。
- 可输出残差图、置信区间和参数相关性。

### 局限

- 实现复杂度更高。
- 可能出现多解，需要全局搜索和合理先验。

## 路线四：统计可靠性与可解释性增强

### 核心思想

不新增复杂物理，而是系统回答“为什么可信”：对峰值提取、折射率、噪声、波数区间、入射角、模型形式做扰动，并观察厚度稳定性。

### 可做实验

- Bootstrap 重采样波数点。
- 对反射率加入测量噪声。
- 改变平滑窗口和峰距阈值。
- 改变拟合波段。
- 改变 $n(\nu)$、$k(\nu)$ 的插值或参数。
- 分别拟合 10 度、15 度，再联合拟合。

## 推荐优先级

1. 先做路线一，建立可复现基线和数据直觉。
2. 再做路线四，用敏感性分析找出最危险假设。
3. 然后做路线三，把多光束干涉作为真正亮点。
4. 最后用路线二补足折射率物理解释。

## 论文可以强化的亮点

- “从基线到物理全谱模型”的递进结构。
- “两个入射角联合反演”的一致性约束。
- “峰谷法 vs TMM 法”的对比表。
- “厚度置信区间”而不只报单点值。
- “残差诊断图”：显示模型在哪些波段解释不好。
- “假设风险雷达图”：界面粗糙度、折射率、吸收、多光束、波数区间。
