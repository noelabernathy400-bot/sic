# 模型真实性验证方法论

## 它解决什么根本问题

模型真实性验证回答：

$$
\text{我为什么相信这个结果？}
$$

不是因为模型复杂，也不是因为 RMSE 小，而是因为多条证据链一致。

## 本项目的真实性证据链

```mermaid
flowchart LR
    A["数据质量"] --> B["条纹周期"]
    B --> C["物理正演"]
    C --> D["双角一致"]
    D --> E["残差无强结构"]
    E --> F["参数敏感性可控"]
    F --> G["全局优化稳定"]
```

## 已完成的验证

| 验证 | 当前结果 | 解释 |
| --- | --- | --- |
| 双角 TMM 低谷 | $7.4\text{--}7.6\ \mu m$ | 支持候选区间 |
| $\nu_p,\gamma,\Gamma$ 敏感性 | 低谷较稳定，但 $\nu_p$ 最敏感 | 需要物理边界 |
| 受约束优化 | $d^\ast=7.465\ \mu m$ | 候选区间未被边界推翻 |
| 残差诊断 | $15^\circ$ 残差更强，自相关高 | 模型尚未闭合 |
| FFT 频域 | 主周期稳定，但厚度依赖 $n_{\mathrm{eff}}$ | 独立验证出现矛盾 |

## 当前结论

最诚实的表述是：

$$
d\approx7.4\text{--}7.6\ \mu m
$$

是 Dong/TMM 强候选区间，但还不是最终被多证据完全闭合的厚度。
