# 输出文件说明

这里放的是代码自动生成的中间结果。它们不是最终论文结论，而是为了让每一步计算都能追溯。

## 最建议先看的文件

如果你想看数学模型和公式，先看：

```text
Methods/数学模型推导-色散FOD与Si复核.md
```

| 文件 | 中文意思 | 什么时候看 |
| --- | --- | --- |
| `dispersion_fod_summary.md` | SiC 色散 FOD 与 Si 厚度复核摘要 | 想快速知道本轮结果 |
| `dispersion_fod_results.csv` | SiC 色散 FOD 详细结果表 | 想查每个角度、峰/谷的数值 |
| `si_thickness_review.csv` | Si 厚度复核表 | 想看 3.5 $\mu m$ 和 5.13 $\mu m$ 的差异 |
| `sic_larruquert_nk_sample.csv` | Larruquert n,k 插值抽样 | 想看不同波数下 n、k 是多少 |

## 基础谱线与极值文件

| 文件 | 中文意思 |
| --- | --- |
| `spectral_summary.csv` | 四个附件的基础统计信息 |
| `extrema_points.csv` | 提取出来的峰和谷的位置 |
| `baseline_thickness_intervals.csv` | 相邻同类极值直接算出的厚度 |
| `fod_fit_results.csv` | 常数折射率 FOD 拟合结果 |
| `spectral_pipeline_summary.md` | 基础谱线流程摘要 |

## 敏感性分析文件

| 文件 | 中文意思 |
| --- | --- |
| `fod_sensitivity_results.csv` | 不同平滑窗口、峰距阈值、波段下的 FOD 结果 |
| `fod_sensitivity_summary.md` | FOD 参数敏感性摘要 |

## 文件名为什么有英文

这些文件名保留英文，是为了方便 Python 脚本、Git、表格工具和后续自动化读取。文件内容和解释会尽量使用中文。
