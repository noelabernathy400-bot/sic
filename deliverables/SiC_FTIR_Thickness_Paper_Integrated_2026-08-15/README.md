# SiC 外延层厚度反演论文交付件

- `main_cn.pdf`：中文阅读版（建议优先阅读）。
- `main_cn.tex`：中文 LaTeX 源文件。
- `main.pdf` / `main.tex`：英文版本及源文件。
- `figures/`：正文插图，均来自本项目已记录的分析输出。

这是综合版：以新版的递进模型叙述和公式短推导为主，同时吸收既有终稿中对测量问题、数据统一、预处理稳健性、滑窗 FFT 和模型假设的完整交代。中文版本在每个核心公式之前补充了符号、物理关系和必要的短推导：条纹相位、峰距、FOD 回归、色散推广、FFT 斜率匹配、Airy 多重反射、剖面化最小二乘、加权 RMSE 与残差自相关。文中将文献公式与本项目推导及诊断目标明确区分。

两份源文件均可在本目录以 XeLaTeX 编译；图路径为相对路径，复制该目录后仍可编译。论文主结论为：现有双角度 FTIR 数据与受约束 TMM 支持 SiC 外延层厚度为 7.4--7.6 um，`7.465 um` 是模型条件下的代表值，而非独立计量认证真值。
